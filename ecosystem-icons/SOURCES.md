# Ecosystem logo sources

The 87 local logo files represent the 89 tool cards (a few products appear in two tracks). They are shown only beside their product names as references to the respective tools.

- [Lobe Icons static SVG](https://github.com/lobehub/lobe-icons), package `@lobehub/icons-static-svg` 1.101.0, for AI product marks.
- [Simple Icons](https://github.com/simple-icons/simple-icons), package `simple-icons` 16.36.0, for brand SVGs. Its published brand color metadata is applied to each icon.
- Official product/repository artwork for Microsoft Agent Framework, AutoGen, GraphRAG, Presidio, and Semantic Kernel, plus the Microsoft Power Automate product icon.
- Website favicons from each remaining tool's own domain, downloaded at build time and served locally.

Brand names and logos remain the property of their owners. The site does not imply endorsement. The icon manifest records the local file used for each tool.
